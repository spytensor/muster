# Code of conduct

Be precise, be kind, argue with ideas and not with people.

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in issues, pull requests, discussions and anywhere else the project is
represented.

To report behaviour that breaks it, write to the maintainers privately through
**Security → Report a vulnerability** on this repository, and say it is a conduct
report. Reports are read by the maintainers only.
