# Proposed Amendments

The paper trail for changes to locked decisions in
[`architecture.md`](architecture.md) (Standard P5).

Process:

1. Open a PR that **only** edits this file with a one-page proposal.
2. Discuss in review. Land this amendment PR **first**.
3. Then open a separate implementation PR that references the amendment.

Each amendment keeps its entry here even after it lands, so the history stays
searchable.
