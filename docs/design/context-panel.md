# 工作面板的「概览」：环境与上下文

**状态**：已实现，2026-11-22（实现与接线见 [`../features/coding.md`](../features/coding.md) 的
「The first view」一节）；当天在桌面 app 里用真实对话验收过：分项、压缩、分隔线与摘要、压缩后接续。
最初是设计，2026-11-22。主人对照 Claude Code 右侧面板（Environment / Context）提出：上一版
只有一个百分比，设计太随意。本文是这一版的完整设计，实现按本文做。

## 先说清楚 Muster 的上下文和 Claude Code 不一样

- **一次回复之内**：agent 读的文件、命令输出都在上下文里，越做越多；快满时 Muster 会先丢掉早先
  步骤的长输出，不够再把前面的部分让模型自己总结（`runtime/compact.ts`）。
- **下一次回复**：重新开始，只带之前对话的文字（人说的话和 agent 的最终回复），不带上一次读过的
  文件和命令输出。最多带最近 200 条消息，更早的不带，也不告诉任何人。
- 所以「用了多少」要分两件事说：**这次回复最后一次调用用了多少**，以及**下一次回复会从多少开始**。
  照搬 Claude Code 的一个数字和一个 Compact 按钮，意思会是错的。

## 面板长什么样（右侧工作面板的第一个视图「概览」）

### 1. 环境

- **这台电脑**，以及当前模式（「Ask first」/「Approve for me」/「Full access」）。改模式仍在输入框上的模式按钮里。
- **每个挂上的文件夹**：名字、完整路径（`~/…`），是仓库的话显示分支和未提交的改动数；不是仓库就写明。
- （项目名与笔记时间未放进这一节：项目页已有，这里只放与这台电脑有关的。）

### 2. 上下文（可以折叠）

- 标题行：`上下文`，右边 `已用 43%` 和 `55.2K / 128K`。
- 一条分段的条，按下面各项的颜色分段，最后是「留给回答」（灰）和「空余」（底色）。
- 分项，每行：色块、名称、token 数、占窗口的百分比：

| 分项 | 包含什么 |
|---|---|
| 指令 | Muster 的规则、agent 自己的指令、回复格式 |
| 工具 | 这次能用的工具的定义（后面写有几个） |
| 技能 | 选用的技能（有几个） |
| 项目与仓库 | 项目说明、项目笔记、仓库自己的说明、分支与改动状态 |
| 记忆 | 这个人让记住的话（有几条） |
| 对话 | 之前的消息；对话被压缩过的话，其中的摘要也算在这里 |
| 这次回复的工作 | 这次回复里的工具调用和结果、过程中说的话 |
| 留给回答 | 压缩线以上留出的空间：给回答本身和下一步的结果 |
| 空余 | 剩下的 |

- 下面两行说明：
  - `距离自动压缩还有 12.4K`：这次回复内，到了这条线 Muster 会先丢早先步骤的长输出，再总结前面的部分。
  - `下一次回复大约从 18.7K 开始`：指令、工具、技能、项目、记忆、对话之和；这次读的文件不带过去。
- **压缩对话** 按钮（见下一节），旁边一行字说它做什么。
- 数字来自哪里：每次调用模型时，Muster 按各部分的字数估算一份分项，记在这次调用的记录上；模型服务
  报回来的真实 prompt token 数是准的，分项按比例缩放到这个总数。没有调用过之前，显示「还没有调用过模型」。
  服务没有报用量时，用估算值，并标注「估算」。

### 3. 压缩对话

- 按下后：把这个对话**到目前为止**的消息让模型总结成一段摘要，存在对话上；以后每次回复带的是
  「摘要 + 摘要之后的消息」，而不是全部原文。原消息一条不删，页面上照常能看到。
- 对话里在被总结的最后一条消息下面出现一条分隔：`以上内容已为 agent 总结（时间）· 查看摘要`，
  点开能看到摘要原文。
- 正在回复时不能按；对话太短（不到 6 条消息）时按钮不可用，说明为什么。
- 回复过程中如果 Muster 自动总结的只是**之前对话的部分**，这份摘要也会存下来，下一次回复直接用，
  不再每次重新总结（以前每次回复都重新总结一遍，又慢又花钱）。
- 摘要的用量算进当天额度，和其他调用一样。

## 不做的

- Claude Code 的「Save」（把环境存成预设）和「Remote Control」：Muster 没有对应的概念。手机端已经能
  跟进同一个对话。
- 手机端暂不显示这个面板（工作面板只在桌面端）。

## 怎么验收

- 一个真实的编码对话：读几个文件、跑测试后，概览里各分项的数字合理（「这次回复的工作」最大），
  总数和模型服务报的一致。
- 按「压缩对话」后：分隔线出现，摘要能打开；下一次回复的「对话」一项明显变小，回复照常能接上之前的事。
- 中英文界面都完整。
